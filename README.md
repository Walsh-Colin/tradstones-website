# Tradstone

A simple, responsive website for Tradstone, a four-piece trad rock band from Lorrha, Co. Tipperary, and Portumna, Co. Galway. Built with HTML, CSS, and JavaScript, it features dark Celtic styling, band member introductions, a Facebook link, and booking contact details.

## GitHub Pages

This site deploys automatically with GitHub Actions whenever changes are pushed to `main`.

1. Push the repository, including `.github/workflows/deploy-pages.yml`, to GitHub.
2. In the repository, open **Settings > Pages**.
3. Set **Build and deployment > Source** to **GitHub Actions**.
4. Open the URL shown in the completed **Deploy static site to GitHub Pages** workflow.

For this repository, the expected URL is https://walsh-colin.github.io/tradstones-website/.
